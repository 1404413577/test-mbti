# 性格测试中心 🧠

一个基于Vue 3的专业心理测试平台，提供多种科学的性格测试工具。

## 🎯 功能特色

- **MBTI 性格测试**：基于荣格心理类型理论的经典16型人格测试
- **情商测试**：全面评估情绪智力的四个核心维度
- **任务性格测试**：分析工作风格和团队角色定位
- **Markdown驱动**：使用Markdown格式管理大量测试题目
- **响应式设计**：完美支持桌面端和移动端

## 🚀 技术栈

- **前端框架**：Vue 3 + Composition API
- **路由管理**：Vue Router 4
- **构建工具**：Vite (Rolldown版本)
- **样式**：CSS3 + 响应式设计
- **内容管理**：Markdown + marked.js
- **部署平台**：Vercel
